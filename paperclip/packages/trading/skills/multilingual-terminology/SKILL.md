## Encoding & Data Integrity

When working with multilingual text:
1. Always use UTF-8 encoding (Paperclip's `detectMojibake()` validates this)
2. PostgreSQL `client_encoding` must be `UTF8`
3. Use Node.js `pg` driver for imports (not `docker exec psql`)
4. API responses include `charset=utf-8` in Content-Type
5. Filenames use RFC 5987 (`filename*=UTF-8''...`) for CJK characters
